# 트리아지 라벨

스킬들은 다섯 가지 표준 트리아지 역할(role)로 이야기한다. 이 문서는 각 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 매핑한다.

| mattpocock/skills 라벨 | 우리 트래커 라벨   | 의미                                  |
| ---------------------- | ------------------ | ------------------------------------- |
| `needs-triage`         | `needs-triage`     | 메인테이너가 검토해야 하는 이슈       |
| `needs-info`           | `needs-info`       | 제보자의 추가 정보를 기다리는 중      |
| `ready-for-agent`      | `ready-for-agent`  | 명세가 충분해 AFK 에이전트가 처리 가능 |
| `ready-for-human`      | `ready-for-human`  | 사람이 직접 구현해야 함               |
| `wontfix`              | `wontfix`          | 처리하지 않음                         |

스킬이 역할을 언급하면(예: "AFK 준비 완료 트리아지 라벨을 붙여라") 위 표의 해당 라벨 문자열을 사용한다.

실제로 쓰는 라벨 이름이 다르면 오른쪽 열만 수정하면 된다.
